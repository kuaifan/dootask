# 仪表盘入口在哪

## 路径
- 桌面端：左侧栏顶部「仪表盘」。
- 页面路由：`/manage/dashboard`。
- 移动端：通过底部导航进入仪表盘页面，布局会随屏幕宽度适配。
- 桌面快捷键：没有直达仪表盘的默认快捷键。

## 进入后看到什么
- 所有登录用户默认可使用个人视角，查看自己负责和协助的任务。
- 右上角切换器可选「列表 / 四象限」，两者都是个人视角的布局。
- 符合部门负责人条件时，切换器末尾增加「部门总览」，点击进入部门负责人视角（部门任务总览）。
- 进入部门负责人视角后，该切换项保持选中：管理多个部门且选中全部时仍显示「部门总览」，只管理一个部门或只选部分部门时显示部门名称（多个部门显示为「研发部 +2」），后面附团队成员数；再次点击可打开「选择团队范围」弹窗。
- 移动端右上角三段切换收起为一个图标按钮：部门负责人点击后在下拉菜单中选择「列表 / 四象限 / 部门总览」，部门视角下菜单底部显示当前团队范围及成员人数（全选多个部门时为「全部部门」），点击可打开「选择团队范围」；图标在部门视角下带成员数角标，超过 99 显示「99+」。普通成员点击图标直接在列表和四象限之间切换。

## 部门负责人视角出现条件
1. 系统设置 `department_owner_project_view` 已开启（新安装或未设置时默认开启，管理员可手动关闭）。
2. 当前用户是至少一个部门的负责人或部门管理员。

详细界面说明见 [[dashboard.concept]]，部门范围规则见 [[dashboard.team-scope.howto]]。
