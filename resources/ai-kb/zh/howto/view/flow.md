# 按工作流状态分栏查看任务

## 入口
- 桌面端 Web：项目详情页顶部筛选按钮（默认显示「全部 (n)」）
- 桌面非触屏端悬停展开下拉；触屏设备和 App 点击展开，在「状态」组勾选一个或多个工作流状态；项目有多条工作流时按工作流分小节（如「评审」小节下的「评审中」）

## 操作步骤
1. 确保项目已配置工作流（项目设置 → 工作流设置；详见 [[project.flow.howto.create]]）
2. 在顶部筛选下拉的「状态」组勾选目标状态（可多选，多个状态之间为「或」）
3. 当前视图（看板 / 列表 / 甘特图）立即过滤，只展示 flow_item_id 命中的任务
4. 点下拉顶部「清空」或按钮上的 × 回到无筛选状态

## 可选筛选维度
筛选下拉分三组，组内多选为「或」，跨组为「且」（详见 [[view.filter.howto]]）：

- **状态**：「未计划」（start_at 为空）+ 各工作流状态（按 `flow_item_id` 过滤）
- **标签**：按任务标签筛选
- **负责人**：按 owner 过滤

## 状态着色
工作流状态有三档着色（status 字段）：

- `start`（起步色）：常用作「待办」「待评审」
- 中间状态：自定义颜色
- `end`（结束色）：常用作「已完成」「已通过」；勾选这种状态时若未开启「显示已完成」会自动打开

## 不支持
- 不支持跨工作流的状态合并（可以同时勾选多条工作流里的状态，但它们仍是不同状态）
- 不支持把工作流分栏当成视图独立保存（每次进入仍是 column / table / gantt 视图）
