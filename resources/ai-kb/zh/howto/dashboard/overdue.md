# 「已超期」任务如何计算

## 统计规则
个人视角「已超期」包含当前用户负责、已经开始、未归档、未完成，并且 `end_at` 小于或等于当前时间的任务。判断使用具体时刻：今天 10:00 截止的任务，在 10:00 后就会显示超期，不需要等到第二天。

## 页面提示
- 顶部卡片显示超期任务数和最久超期天数。
- 点击卡片会展开超期分组并滚动到该位置。
- 截止时间会显示「逾期 N 小时」或「逾期 N 天」。
- 列表按截止时间排序，较早截止的任务靠前。

## 常见处理
1. 已完成：直接更新任务状态。
2. 仍需继续：进入任务详情修改截止时间。
3. 不再处理：按项目权限归档或删除任务。

仪表盘只负责分类和提示，不会自动延期，也不会自动修改任务字段。
