# 在线更新系统（服务端）

「系统更新」用于管理员在网页上把 DooTask 服务端更新到最新版本，效果等同于运维在服务器上执行 `./cmd update`。它只更新服务端，不更新成员的桌面端 / APP 客户端（客户端更新见 [[electron-client.update.howto]]）。

## 入口
- 设置 →「系统更新」（仅管理员可见，位于「更新日志」上方；有新版本时右侧显示新版本号）
- 右上角头像下拉 →「更新系统」（仅管理员可见，且只在有新版本时显示）
- 有系统新版本时，管理员头像右上角会出现红点

## 操作步骤
1. 进入「系统更新」页，页面显示当前版本；有新版本时显示「发现系统新版本」、最新版本号和更新日志
2. 点「检查更新」可立即重新检查（检查结果默认缓存 10 分钟）
3. 点「立即更新系统」，在弹窗中输入当前管理员的登录密码确认
4. 更新开始后，所有在线成员会收到「系统正在更新」提醒
5. 页面依次显示进度：准备更新 → 获取更新 → 备份数据库 → 更新代码 → 安装依赖 → 迁移数据库 → 重启服务 → 检查服务，并实时输出日志
6. 「重启服务」阶段页面会短暂连不上服务器，属正常现象，页面会自动等待恢复
7. 显示「系统更新完成」后，点「刷新页面」使用新版本

## 字段默认值
- 每次在线更新前都会自动备份数据库，备份文件位于服务器 `docker/mysql/backup/` 目录
- 更新日志保存在服务器 `docker/logs/update/` 目录
- 在线更新默认开启，运维可在服务器 `.env` 设置 `ONLINE_UPDATE=false` 关闭

## 不支持
- 不支持定时更新、选择版本、跨分支更新
- 不支持在网页上一键回滚
- 普通成员看不到系统更新入口
