# 重复 / 循环任务

## 是什么
DooTask 任务支持循环重复（字段 `loop` 重复周期 + `loop_at` 下个周期时间），常用于「每日站会」「每周周报」类型任务。系统定时任务每分钟检查一次，到达 `loop_at` 时自动创建下一份新任务，原任务是否已完成不影响生成。

## 支持的周期
- `day` 每天
- `weekdays` 工作日（周一至周五）
- `week` 每周
- `twoweeks` 双周
- `month` 每月
- `year` 每年
- 自定义天数（输入正整数，如 3 表示每 3 天；0 或非数字会被拒绝，提示「重复周期选择错误」）
- `never` 不重复（默认）

## 入口
- 桌面端：任务详情页 →「重复周期」项（未设置时在添加项菜单里选「重复周期」），选预设周期或「自定义」
- 设置后鼠标悬停周期文字可看到「下个周期」时间
- 不要求填截止时间：以开始时间为基准计算，未设开始时间则以当天 0 点为基准

## 工作原理
1. 设置或修改周期、计划时间时，服务端按 `loop` 和开始时间算出 `loop_at`
2. 到 `loop_at` 后，系统创建新任务，复制：标题、描述、负责人和协助人员、附件、优先级、可见性、子任务
3. 新任务开始时间等于原任务的 `loop_at`，时长与原任务相同；状态为未完成（项目有工作流则回到起始状态），子任务也重置为未完成
4. 新任务自己算出下一个 `loop_at`；原任务的周期被关闭（`loop` 清空），并记一条日志
5. 新任务与原任务自动建立任务关联，双方任务详情「关联任务」区可互相跳转，任务动态各记一条「关联任务」
6. 创建失败时整体回滚，不会留下半成品，任务日志记「生成重复任务失败：原因」，到期后 10 分钟内每分钟重试

## 不支持
- 不能为同一任务并行启用多个周期
- 子任务不能独立设置循环
- 所属项目已被删除或已归档的任务不再自动生成新周期任务；这类残留任务可在任务详情顶部横幅点「删除任务」清理
