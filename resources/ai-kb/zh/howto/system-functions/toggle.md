# 怎么启用或停用系统功能（工作报告、日历、收藏、最近打开、签到）

## 入口
- 桌面端：左侧栏「应用」→ 管理员区「应用商店」→ 找到「系统功能」应用

## 操作步骤
1. 在应用商店打开「系统功能」应用
2. 进入该应用的安装页（已安装时按钮为「重新安装」，未安装时为「安装」）
3. 在「应用配置」里按需打开或关闭五个开关：工作报告、日历、我的收藏、最近打开、签到打卡
4. 点击「重新安装」提交，配置立即保存，无需等待容器启动
5. 回到主界面，入口随即按新配置显示或隐藏；其他成员刷新页面或重新进入「应用」后生效

## 字段默认值
| 开关 | 默认 |
|---|---|
| 工作报告 | 开启 |
| 日历 | 开启 |
| 我的收藏 | 开启 |
| 最近打开 | 开启 |
| 签到打卡 | 开启 |

## 一次隐藏全部入口
在应用商店卸载「系统功能」应用，五个功能的入口全部隐藏。重新安装后恢复。
