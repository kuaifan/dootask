# 「系统功能」应用是什么

## 定义
「系统功能」（应用 ID：system-functions）是 DooTask 的内置应用，用来统一管理五个内置功能的入口：工作报告、日历、我的收藏、最近打开、签到打卡。它在应用商店（AppStore）中安装、配置和卸载。

## 关键属性
- 每个功能对应一个开关字段，默认全部开启
- 新部署和升级上来的实例会自动安装「系统功能」并启用全部功能；已有配置不会被覆盖
- 开关对该功能的所有入口统一生效：应用中心卡片、头像下拉菜单、左侧导航
- 卸载「系统功能」后，五个功能的入口全部隐藏；重新安装即可恢复

## 各功能受控的入口
| 功能 | 受控入口 |
|---|---|
| 工作报告 | 应用中心「工作报告」卡片及未读角标、头像菜单「工作报告」 |
| 日历 | 左侧导航「日历」、竖屏应用中心「日历」卡片；停用后访问日历页会回到仪表盘 |
| 我的收藏 | 头像菜单「我的收藏」、应用中心「我的收藏」卡片 |
| 最近打开 | 头像菜单「最近打开的任务」、应用中心「最近打开」卡片 |
| 签到打卡 | 应用中心「签到打卡」卡片、「导出签到数据」入口 |
